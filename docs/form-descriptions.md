# Google Form field text

Only needed if you build the Form by hand (see the README). The phone page submits to the Form directly, so participants never see this text.

## Form description

**TED-AI**: an AI system at least as good as top human experts at virtually all cognitive tasks. Operationally, it could fully automate 95% of US remote-work jobs given the resources of a large tech company and three months to prepare. Definition from the [AI Futures Project](https://blog.aifutures.org/p/ai-futures-model-dec-2025-update).

Enter each answer as a year, for example 2035. Each year must be later than the one before.

## Fields

Create seven short-answer fields in this order. The titles say what each year means, so the five percentile fields need no description.

| Title | Description |
|---|---|
| Name or initials | Optional. Labels your curve on the shared screen. |
| p10 — 10% chance before this year | |
| p25 — 25% chance before this year | |
| p50 — Median (50% chance by this year) | |
| p75 — 75% chance before this year | |
| p90 — 90% chance before this year | |
| Gut P(TED-AI by 2030), % | Optional. Your gut sense of the chance (0–100) that TED-AI arrives by the end of 2030, before looking at your other answers. |
